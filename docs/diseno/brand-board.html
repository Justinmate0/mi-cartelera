Sí y no

Sí

  • Clases de Bootstrap primero, componentes propios después.
  • Colores solo con tokens de :root.
  • CSS de cada pantalla nueva en src/styles/.
  • Probar a 1280px y a 390px.

No

  • Hexadecimales o rgba() fuera de :root.
  • Tailwind, otra librería de UI o el JavaScript de Bootstrap.
  • Estilos en línea, --bs-* o !important.
  • Cambiar cómo se ven las pantallas de E1.
